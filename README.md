# NEXA 初号機
無料・iPhone向けの最小基本型プロトタイプです。

## 今回の基本型強化
- 目的 / 現在地 / 次の一手
- 状態保存・再開サマリー
- 判断記録と判断変更の検知
- 判断理由の必要時確認
- 前提条件の記録
- NEXA推奨と推奨理由・確信度・重要度
- 優先順位の整理（高 / 中 / 低）
- 前提条件との矛盾候補の検知
- 「今は決めない」を正式な判断として記録
- 未解決事項の管理
- 保留・非実装事項の管理（初号機を膨らませない）
- 「分からない」を許容
- 事実 / 推測 / 意見を分ける基本方針
- NEXAは推奨理由を明示し、判断材料が不足する場合は無理に決めない
- 質問しすぎない介入方針
- 攻撃しない設計
- 外部APIなし、localStorage利用

## 重要な制約
本版の自然言語理解はルールベースの基本型です。曖昧な会話を完全に理解するものではなく、断定を避ける設計です。

## データ
ブラウザのlocalStorageに保存します。ブラウザ/サイトデータを消すと状態も消えるため、重要な状態は別途バックアップしてください。
